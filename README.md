# 蘇澳海事首頁改版提案

直接以 Chrome、Safari 或 Edge 開啟 `index.html` 即可預覽，不需要安裝套件或建置。

也可以在這個資料夾執行 `python3 -m http.server 8080 --bind 127.0.0.1`，再開啟 `http://127.0.0.1:8080`。

- `index.html`：首頁結構與導覽連結。
- `style.css`：海洋藍、暖金與留白的視覺樣式，包含手機、平板與桌面版。
- `script.js`：校園與競賽輪播、YouTube 播放視窗、公告分類、服務分頁、首頁搜尋、圖片放大及行動選單。
- `news-data.js`：2026-10-10 從原官網讀取的公開公告快照，並非即時公告系統。
- `assets/`：由使用者圖片轉出的 WebP 與原官網正式校徽。
- `圖片/`：使用者原始圖片，未更動。

## 這一版的範圍

純 HTML + CSS + 原生 JavaScript，無外部程式庫、字型 CDN 或後端。先供首頁風格確認。公告、科別、招生與校務服務連結會另開原校網的對應頁面；搜尋只索引本頁公告及服務，不是全站搜尋。頁尾標示公告快照日期。YouTube 縮圖已下載至本機；點選影片後才建立 `youtube-nocookie.com` 播放器，關閉視窗即移除播放器並停止播放。

輪播提供前後切換、照片選擇、暫停按鈕，游標停留或鍵盤操作時暫停；遵循系統「減少動態效果」偏好。公告與服務分頁可用左右方向鍵、Home、End 操作。圖片與搜尋視窗可按 Escape 關閉。

## 設計與內容來源

- 架構參考：[臺北市立建國高級中學](https://www.ck.tp.edu.tw/nss/p/index) 的白色校名區、深藍導覽列、校園大圖與分類公告。
- 學校資訊及連結：[國立蘇澳海事原官網](https://www.savs.ilc.edu.tw/home)。
- 圖片：使用者提供的 `圖片/`；正式校徽取自原校網頁尾。
- `圖片/得獎海報/114專題.jpg` 檔名雖為 114，圖面文字是「115 全國專題實作及創意競賽」，首頁依圖面標示。

本次僅建立本機檔案，未部署網站。

瀏覽器自動化不允許開啟 file:// 協定，因此實際畫面驗證使用本機 HTTP；頁面本身不使用 fetch、模組或外部相依，可由使用者直接開啟 HTML。
